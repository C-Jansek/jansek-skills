# Jansek mode

## Usage

Start any request prefixed by /jansek-mode.
The skill will choose from the correct playbook to act on your request.
The playbook will guide the agent to handle the request, using reusable skills for parts of the request.

## Playbooks

Playbooks are a series of steps the agent will execute to respond to a specific request.

| Task                    | Playbook                                                       |
|-------------------------|----------------------------------------------------------------|
| Create or edit skill    | ./skills/jansek-mode/references/playbooks/write-skill.md       |
| Create or edit playbook | ./skills/jansek-mode/references/playbooks/write-playbook.md    |
| Implement a feature     | ./skills/jansek-mode/references/playbooks/implement-feature.md |
