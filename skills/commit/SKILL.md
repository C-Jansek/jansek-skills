---
name: commit
description: Ensure correct commit sizing, content and structure along with a descriptive message. Use when committing code to version control.
---

A commit is a collection of changes to your (source) code. You group changes together based on a shared goal: to change functionality, to refactor logic etc.

A commit helps to describe the changes at a higher level. It allows retracing the steps that have been taken before.

A commit has a message which explains the change and the rationale behind the changes. They are an abstraction over the full collection of changes.
The message title describes broadly what changed. It should be short, as to be scannable in one sentence (<70 characters).
The message body goes more in depth, describing why something changed. It might also include an expansion of the title in more depth. It can also mention unexpected changes part of the commit.

Agents must use /commit-attribution.
