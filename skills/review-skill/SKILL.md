---
name: review-skill
description: "Review a handwritten skill or playbook provided by the user."
---

Read the provided skill or playbook file along with referenced files influencing its behavior.
Critique it using /writing-for-agents. Verify that the skill or playbook adheres to the rules in /writing-for-agents.
Display prioritized findings with references to line numbers to the user.

Return the findings or report when no findings remain.

If the user's intent with the skill or playbook is unclear, ask questions using /grilling to discover the intent.
